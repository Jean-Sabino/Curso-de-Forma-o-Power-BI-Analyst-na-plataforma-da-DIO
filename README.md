# 📊 Formação Power BI Analyst - DIO

Repositório dedicado ao registro da minha jornada, projetos práticos e desafios desenvolvidos na **Formação Power BI Analyst** da plataforma [DIO](https://www.dio.me/). 

O objetivo desta formação é dominar o processo analítico de ponta a ponta, desde a extração e tratamento de dados (ETL) até a criação de relatórios interativos e publicação de workspaces no ecossistema Power BI.

---

## 🛠️ Tecnologias e Conceitos Aplicados
* **Power BI Desktop:** Modelagem de dados relacional, DAX (Data Analysis Expressions) e Power Query.
* **Ferramentas de Suporte:** Microsoft Excel para manipulação e estruturação de bases auxiliares.
* **Controle de Versão:** Git e GitHub para organização de portfólio e versionamento de código.

---

---

## 🚀 Competências Desenvolvidas na Formação
* **Processo de ETL Eficiente:** Limpeza, transformação e carga de dados sem perda de performance.
* **Modelagem Relacional:** Conexão entre tabelas fato e dimensão, garantindo a integridade dos dados e otimização de medidas.
* **Data Storytelling & UX:** Criação de visuais limpos, intuitivos e direcionados à tomada de decisão estratégica.
* **Publicação e Compartilhamento:** Gestão de relatórios e integração com recursos da Microsoft.
