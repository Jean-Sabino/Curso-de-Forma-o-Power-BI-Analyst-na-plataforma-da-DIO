# 📊 Formação Power BI Analyst - DIO

Repositório dedicado ao registro da minha jornada, projetos práticos e desafios desenvolvidos na **Formação Power BI Analyst** da plataforma [DIO](https://www.dio.me/).

O objetivo desta formação é dominar o processo analítico de ponta a ponta: desde a extração, limpeza e transformação de dados (ETL no Power Query) até a modelagem relacional, criação de medidas dinâmicas com DAX, visualização estratégica de dados (Data Storytelling & UX/UI) e publicação no Power BI Service.

---

## 🛠️ Tecnologias, Recursos e Conceitos Aplicados

* **Power BI Desktop:** Modelagem de dados relacional, linguagem DAX (*Data Analysis Expressions*) e Power Query (M).
* **Recursos Avançados de BI:** Tooltips personalizadas (dicas de ferramenta flutuantes), menu lateral retrátil via *bookmarks* (favoritos), Árvore de Decomposição (*Decomposition Tree*), Gráfico de Cascata (*Waterfall Chart*) e seleção dinâmica de visuais.
* **UI/UX Design:** Desenvolvimento de layouts corporativos (incluindo *Dark Mode* e capas personalizadas), alinhamento de hierarquia visual e navegação intuitiva.
* **Ferramentas de Suporte:** Microsoft Excel para validação e manipulação de bases.
* **Controle de Versão:** Git e GitHub para documentação e gerenciamento do portfólio.

## 🚀 Competências Desenvolvidas na Formação

* **ETL e Tratamento de Dados:** Limpeza, padronização e estruturação eficiente das bases via Power Query.
* **Modelagem Relacional (Star Schema):** Conexão entre tabelas fato e dimensão, assegurando integridade e performance nas métricas.
* **Data Storytelling & UX/UI:** Design funcional focado na facilidade de leitura e tomada de decisão por gestores e executivos.
* **Interatividade Avançada:** Uso de filtros dinâmicos (*slicers*), ações de redefinição de telas e visuais orientados a diagnósticos preditivos e analíticos.
